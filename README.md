# Zenith Analytica - Tablero de Inteligencia de Ventas

![Dashboard Preview](https://raw.githubusercontent.com/JorgeTrip/dashboard-demo/main/public/preview.png)

## 📊 Descripción del Proyecto

**Zenith Analytica** es una plataforma interactiva de inteligencia de ventas diseñada para **Zenith Naturals**. Este proyecto representa una interfaz analítica premium que transforma datos complejos en insights visuales accionables. 

Este dashboard fue desarrollado como una pieza de exhibición para portafolio profesional, enfocándose en la excelencia visual, la optimización del rendimiento y una experiencia de usuario (UX) fluida.

## 🚀 Tecnologías Utilizadas

- **Core**: [Next.js 14+](https://nextjs.org/) (App Router)
- **Lenguaje**: [TypeScript](https://www.typescript.org/) para un desarrollo robusto y tipado.
- **Estilos**: [Tailwind CSS](https://tailwindcss.com/) con un sistema de diseño basado 100% en variables CSS dinámicas.
- **Visualización de Datos**: [Recharts](https://recharts.org/) para gráficos interactivos y reactivos.
- **Geolocalización**: [React Leaflet](https://react-leaflet.js.org/) para el mapeo regional de ventas.
- **Iconografía**: [Lucide React](https://lucide.dev/).
- **Animaciones**: Tailwind transitions y micro-interacciones suaves.

## ✨ Características Principales

- **Sistema de Temas Dinámico**: Soporte completo para Modo Claro (Light) y Modo Oscuro (Dark) sincronizado mediante variables globales de CSS.
- **Filtrado Multidimensional**: Análisis de ventas por periodo, vendedor, región y categoría de producto.
- **Comparativa de Métricas**: Alternancia instantánea entre Ingresos (Revenue) y Unidades Vendidas en todos los componentes visuales.
- **Diseño Adaptativo (Responsive)**: Experiencia optimizada para móviles, tablets y monitores de alta resolución.
- **Consistencia Visual**: Refactorización profunda para asegurar que cada píxel respete la paleta de colores global, eliminando el uso de colores "hardcoded".

## 🛠️ Instalación y Uso

1. Instalar dependencias:
   ```bash
   npm install
   ```

2. Ejecutar en modo desarrollo:
   ```bash
   npm run dev
   ```

3. Abrir [http://localhost:3000](http://localhost:3000) en el navegador.

## 📝 Nota Técnica

Este proyecto ha pasado por un proceso de refactorización integral para unificar la renderización entre diferentes plataformas, asegurando que el contraste y la legibilidad sean óptimos tanto en dispositivos móviles como en pantallas de escritorio.
